# Datos de la aplicación

Esta carpeta contendrá únicamente registros revisados y aprobados. Durante el MVP, la hoja Excel de `docs/` es el área de investigación y estos archivos son la fuente publicada de la aplicación.

- `productos.csv`: identificación del producto o sistema.
- `afirmaciones_tecnicas.csv`: propiedades y afirmaciones vinculadas a fuentes.
- `fuentes.csv`: procedencia documental.
- `precios_historicos.csv`: observaciones comerciales fechadas.

Los archivos comienzan con sus encabezados y sin registros publicados. Los datos demostrativos que actualmente aparecen en `index.html` deberán migrarse solamente después de validación.
