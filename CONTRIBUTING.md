# Cómo contribuir

## Principio de trabajo

Cada recomendación debe poder rastrearse hasta un producto o sistema definido, una afirmación técnica, una fuente concreta y una regla de decisión versionada.

## Flujo

```text
Borrador → Enviado → Revisión de datos → Revisión técnica → Aprobado → Publicado
                    ↘ Correcciones solicitadas ↗
```

## Responsabilidades

- **Investigador/a:** registra el producto, cita fuentes y declara vacíos o incertidumbre.
- **Revisor/a de datos:** revisa identificadores, unidades, fechas, duplicados, enlaces y campos obligatorios.
- **Revisor/a técnico:** verifica que las conclusiones correspondan a la evidencia y que no falten condiciones de uso.
- **Mantenedor/a:** integra únicamente registros aprobados y conserva el historial de cambios.
- **Profesor o comité:** aprueba criterios excluyentes, pesos y cambios metodológicos.

## Requisitos mínimos de un aporte

- Producto comercial o sistema constructivo claramente identificado.
- Presentación, espesor, dimensiones o configuración aplicable.
- Cada propiedad con valor, unidad, condición de ensayo y fuente.
- Cada compatibilidad o restricción vinculada con evidencia.
- Precio con proveedor, fecha, moneda, unidad y alcance.
- Autor del aporte y responsable de revisión.

`Sin evidencia suficiente` es un resultado válido. La ausencia de información nunca debe interpretarse como aptitud.

## Pull Requests

- Use una rama por aporte.
- Evite combinar varios temas no relacionados.
- Explique qué registros cambian y por qué.
- No incorpore documentos, imágenes o fichas de terceros sin permiso de redistribución; enlace la fuente original.
- Un cambio técnico requiere revisión de datos y revisión técnica antes de fusionarse.
